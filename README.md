# RentEase – Frontend

Smart Rental & Property Management System (React.js Frontend).

---

## 📌 Technology Stack

- **Framework:** React.js (Vite)
- **Styling:** CSS3 (Clean Responsive Card-Based Layout)
- **HTTP Client:** Axios (REST API communication)
- **Deployment:** Render / Vercel / Netlify

---

## 🚀 Features

- **Properties Tab:** View all available rentals, search by title/location, add new properties, edit, delete, and apply for rent.
- **Tenants Tab:** Register tenants with contact details, manage tenant records.
- **Rental Requests Tab:** Review booking applications and approve/reject requests.

---

## 🛠️ How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open in browser:
   ```
   http://localhost:3000
   ```
